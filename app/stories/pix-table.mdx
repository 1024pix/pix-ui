# PixTable

Une table qui prend en argument des headers et des data.

<Story of={ComponentStories.Default} height={200} />

## Usage

```html
<PixTable
  @data={{this.data}}
  @headers={{this.headers}}
  @caption={{this.caption}}
/>
```
