# PixBannerAlert

Une `PixBannerAlert` permet de mettre en avant une information importante.

> Il est possible de surcharger le style d'une `<PixBannerAlert>` via l'attribut `class` ainsi que de passer n'importe quel attribut sur sa `div` wrapper (par exemple, un `aria-label`)

## Usage

```html
<PixBannerAlert> Bannière Info par défaut </PixBannerAlert>

<PixBannerAlert @type="warning"> Bannière Warning </PixBannerAlert>

<PixBannerAlert @type="error"> Bannière Error </PixBannerAlert>

<PixBannerAlert @actionLabel="Liste des campagnes" @actionUrl="authenticated.campaigns">
  Bannière avec une route pour lien
</PixBannerAlert>

<PixBannerAlert @actionLabel="Ajouter des élèves" @actionUrl="https://orga.pix.fr/eleves">
  Bannière avec une route externe
</PixBannerAlert>

<PixBannerAlert @type="warning" @canCloseBanner="true">
  Bannière possédant un bouton de fermeture
</PixBannerAlert>
```
