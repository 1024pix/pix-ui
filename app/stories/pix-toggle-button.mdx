# PixToggleButton

Affiche un bouton à deux états.

Le label est géré avec un [PixLabel](?path=/docs/forms-label--docs), tous les arguments de ce composant peuvent être passés au `PixToggleButton`.

## Défaut
```html
<PixToggleButton>
  <:label>Mon super label</:label>
  <:viewA>Option 1</:viewA>
  <:viewB>Option 2</:viewB>
</PixToggleButton>
```
<Story of={ComponentStories.Default} height={200} />


## Option 2 sélectionnée par défaut
```html
<PixToggleButton @toggled={{true}}>
  <:label>Mon super label</:label>
  <:viewA>Option 1</:viewA>
  <:viewB>Option 2</:viewB>
</PixToggleButton>
```
<Story of={ComponentStories.Toggled} height={200} />
