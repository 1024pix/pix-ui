# Pix Select

Affiche un menu déroulant avec la liste des options fournies.

Les options sont représentées par un tableau d'objet contenant les propriétés value, label, icon et iconTitle.

> **⚠️** **Il est nécessaire d'avoir au moins un label ou un placeholder !**

> Pour aider l'utilisateur, rajoutez un placeholder cohérent !

### Argument `@texts` (obligatoire)

Tous les textes permanents du composant passent par l'argument `@texts` afin de faciliter la traduction lors d'un changement de locale :

- `placeholder`, obligatoire : placeholder du menu déroulant et label de l'option par défaut
- `selectSearchLabel`, si `isSearchable=true`: label du champ de recherche (accessibilité)
- `searchPlaceholder`, si `isSearchable=true`: placeholder du champ de recherche
- `emptySearchMessage`, si `isSearchable=true`: message affiché si la recherche ne retourne aucun résultat
- `subLabel`: descriptif complétant le label
- `requiredLabel`: texte indiquant que le champ est requis


- **⚠️** Pour un champ de filtre sur des résultats qui ne s'affichent pas dans une liste déroulante, utilisez plutôt le [PixSearchInput](?path=/story/others-searchinput--default).

## WithSearch

> Il est possible de prendre le contrôle sur le filtre effectué par la recherche en utilisant l'argument `@onSearch`.
Un exemple est disponible dans l'environnement local sur la page `/select`
```html
<PixSelect
  ...
  @isSearchable={{true}}
  @options={{customFilteredOptions}}
  @onSearch={{{updateOptions}}}
  @texts={{texts}}
  ...
>
  ...
</PixSelect>
```

## Usage

```html
<PixSelect
  @className="{{className}}"
  @options="{{options}}"
  @onChange="{{onChange}}"
  @value="{{value}}"
  @isSearchable="{{isSearchable}}"
  @screenReaderOnly="{{screenReaderOnly}}"
  @errorMessage="{{errorMessage}}"
  @placement="{{placement}}"
  @iconName="{{icon}}"
  @texts={{hash
    placeholder="Sélectionner"
    subLabel="Mon sous-label"
    requiredLabel="obligatoire"
    selectSearchLabel="Rechercher"
    searchPlaceholder="Rechercher..."
    emptySearchMessage="Aucune option"
  }}
>
  <:label>{{label}}</:label>
</PixSelect>
```
