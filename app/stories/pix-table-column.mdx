# PixTableColumn

Une colonne d'un [PixTable](/docs/data-display-table--docs), gère l'affichage de l'en-tête et des cellules d'une colonne.

<Story of={ComponentStories.Default} height={400} />

## Usage

```html
<PixTable @data={{this.data}} @caption={{this.caption}}>
  <:columns as |context|>
    <PixTableColumn @context={{context}}>
      <:header>
        Info
      </:header>
      <:cell as |row|>
        <PixIcon @name='info' @title={{concat row.name ' a ' row.age ' ans'}} />
      </:cell>
    </PixTableColumn>
  </:columns>
</PixTable>
```
