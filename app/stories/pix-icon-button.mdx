# Pix Icon Button

Le PixIconButton permet de créer un bouton contenant une icône font-awesome.

## Default

Le bouton en version big et sans fond grisé.

<Story of={ComponentStories.Default} height={60} />

## Size

Le bouton en version small. (big étant la valeur par défaut)

<Story of={ComponentStories.size} height={60} />

## Disabled

Exemple avec le bouton désactivé

<Story of={ComponentStories.disabled} height={60} />

## Variant

Le bouton, version "secondary". Pour avoir le design original, il suffit de ne pas ajouter cet attribut.

<Story of={ComponentStories.secondary} height={60} />

## Accessibilité / aria-label

L'attribut `aria-label` étant indispensable pour l'accessibilité de ce composant, la propriété `ariaLabel` a été ajouté.

## Color

⚠️ Cette propriété est **dépréciée**. L'icône du bouton ne peut avoir qu'une seule couleur.

## Usage

Par défaut

```html
<PixIconButton @ariaLabel="L'action du bouton" @iconName="icon" @triggerAction="{{triggerAction}}" />
```

Bouton de fermeture

```html
<PixIconButton
  @ariaLabel="L'action du bouton"
  @iconName="add"
  @triggerAction="{{triggerAction}}"
/>
```

Bouton d'action

```html
<PixIconButton
  @ariaLabel="L'action du bouton"
  @iconName="ChevronRight"
  @triggerAction="{{triggerAction}}"
  @size="small"
/>
```

État disabled

```html
<PixIconButton
  @ariaLabel="L'action du bouton"
  @iconName="add"
  @isDisabled={{true}}
/>
```
