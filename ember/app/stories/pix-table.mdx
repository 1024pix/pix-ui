# PixTable

Une table qui prend en argument des data et en `block content` des [PixTableColumn](/docs/data-display-table-tablecolumn--docs).

## Exemple basique
<Story of={ComponentStories.Default} height={400} />

```html
<PixTable @variant={{this.variant}} @data={{this.data}} @caption={{this.caption}}>
  <:columns as |row context|>
    <PixTableColumn @context={{context}}>
      <:header>
        Nom
      </:header>
      <:cell>
        {{row.name}}
      </:cell>
    </PixTableColumn>
    <PixTableColumn @context={{context}}  class='table__column--wide'>
      <:header>
        Description
      </:header>
      <:cell>
        <i>{{row.description}}</i>
      </:cell>
    </PixTableColumn>
    <PixTableColumn @context={{context}} @type="number">
      <:header>
        Age
      </:header>
      <:cell>
        {{row.age}}
      </:cell>
    </PixTableColumn>
  </:columns>
</PixTable>
<style>
  .table__column--wide { width: 300px; }
</style>
```
